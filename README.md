## About

**PlumBot** is a Discord bot designed to provide moderation, management, utility and community features in one place.

The goal is to make server management easier while providing useful tools for both staff members and the community.

PlumBot is actively developed and regularly receives new features, improvements and fixes.

---

## Features

### 🛡️ Moderation

Tools designed to help moderators manage their communities.

- Warning management
- Moderation records
- Permission management
- Server rules
- Moderation interactions
- Server-specific configuration

### ⚙️ Utilities

Useful features for users and server administrators.

- Slash commands
- Server utilities
- User utilities
- Automated notifications
- Social links
- Custom server configuration

### 🔔 Automation

PlumBot can automate various actions and notifications to make managing a community easier.

More automation features may be introduced as the project develops.

---

## Privacy

PlumBot only processes information necessary for its features to operate.

Depending on the feature being used, this may include:

- Discord user IDs
- Server IDs
- Channel and role IDs
- Server configuration
- Moderation records

PlumBot does **not** intentionally collect Discord passwords, payment information or account credentials.
